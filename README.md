# Bilim Hub · Әдеби цифрлық экосистема

Сайтқа тек әкімші кіреді. Логин мен құпиясөз middleware.js ішінде хэш түрінде орнатылған.

Өзгерту керек болса:

1. Vercel → осы жоба → **Settings → Environment Variables**
2. `ADMIN_USER` = логин, `ADMIN_PASSWORD` = құпиясөз (Environment: Production, Preview)
3. **Deployments → соңғы деплой → Redeploy**

Логинді немесе құпиясөзді өзгерту үшін айнымалыны өзгертіп, қайта Redeploy жасаңыз.
